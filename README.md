# SPYROOM — 4 адамға арналған онлайн «Шпион»

Бұл жоба телефонда да, компьютерде де ашылатын веб-ойын. Нақты мультиплеер жұмыс істеуі үшін Firebase Realtime Database конфигурациясын қосу керек.

## Ішіндегі файлдар
- `index.html` — экрандар мен ойын интерфейсі
- `style.css` — дизайн және мобильді бейімдеу
- `app.js` — бөлме коды, мультиплеер логикасы, дайын батырмалары, раунд пен ұпай
- `categories.js` — ойын категориялары мен сөздер

## Категориялар
- Танымал адамдар — 50 атау
- Спорт — 50 атау
- Место — 50 орын
- Машина маркасы — 50 марка
- Мемлекеттер — әлем елдерінің кеңейтілген тізімі

## Firebase баптау
1. https://console.firebase.google.com/ сайтына кіріп, жаңа Firebase project жаса.
2. Build → Realtime Database → Create Database таңда.
3. Project settings → General → Your apps → Web app қосып, Firebase config мәліметтерін көшір.
4. `app.js` басындағы `firebaseConfig` ішіндегі `YOUR_...` мәндерін өзіңнің Firebase config мәндерімен ауыстыр.
5. Realtime Database → Rules бөлімінде төмендегі уақытша ережелерді қолдануға болады ТЕК тест үшін:

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

**Қауіпсіздік ескертуі:** бұл ашық ережелер оқу/сынақ үшін ғана. Мұндай ережелермен бөлме кодын білген адам деректерді оқи/өзгерте алады. Ойынды көпшілікке жариялар алдында Firebase Authentication және қауіпсіз Database Rules немесе серверлік тексеру қосу қажет. Қазір раунд деректерінің ішінде рөлдер сақталады, сондықтан бұл нұсқа — жұмыс прототипі, толық cheat-proof production нұсқасы емес.

## GitHub Pages арқылы жариялау
1. GitHub-та жаңа repository жаса.
2. Осы папкадағы төрт файлды (`index.html`, `style.css`, `app.js`, `categories.js`) repository-ге жүкте.
3. Repository → Settings → Pages → Deploy from a branch → `main` және `/ (root)` → Save.
4. Firebase конфигурациясын енгізген соң GitHub Pages берген сілтемені достарыңа жібер.

## Ойын ережесі
- Бөлме коды кездейсоқ 6 таңбадан тұрады.
- Әр бөлмеде дәл 4 ойыншы болуы керек; төртінші адам қосылғанда категория кезеңі ашылады.
- Төртінші ойыншы қосылғанда категория таңдау ашылады.
- Әр ойыншы категорияларды таңдап, «Категорияға дайынмын» батырмасын басады. Барлық төрт ойыншы дайын болса, раунд автоматты басталады.
- Бір шпион кездейсоқ тағайындалады. Қалғандары бірдей құпия сөз алады.
- Шпион сөзді дұрыс тапса 3 ұпай алады; таппаса қалған ойыншылардың әрқайсысы 1 ұпай алады.

## Ескерту
Бөлме иесі — раундты бастайтын ойыншы. Бөлме иесі байланысын жоғалтса, жаңа раунд бастау үшін сол бөлмені қайта құру қажет болуы мүмкін.
